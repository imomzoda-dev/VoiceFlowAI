**Downloads:** Windows — `VoiceFlow-AI-Setup-1.0.8.exe` · macOS Apple Silicon (M1–M5) — `VoiceFlow-AI-1.0.8-arm64.dmg` · macOS Intel — `VoiceFlow-AI-1.0.8-x64.dmg`

**VoiceFlow AI 1.0.8** — a better Tajik model, and no more made-up text from silence or noise.

- **New Tajik model v3.1** ([whisper-large-tajik](https://github.com/imomzoda-dev/whisper-large-tajik)): trained on about 220 hours of Tajik speech. Fewer mistakes — 14.4% of words wrong on FLEURS (v2: 15.5%, the first model: 22.3%), 36.7% on live speech (v2: 38.6%) — and correct capitals, commas, full stops and Tajik letters (ғ ӣ қ ӯ ҳ ҷ). If you have the Tajik model, it is replaced automatically a few seconds after the update.
- **Future Tajik models arrive by themselves**, including a switch to a larger model (Large v3 Turbo): each new release is checked (size and SHA-256) and switched in between dictations.
- **Silence and noise give no text.** VoiceFlow AI now recognises only the parts of a recording where someone speaks (voice activity detection). Before, a pause, a fan or street noise could turn into a whole invented sentence. It is also faster. *Settings → Recognition → Ignore silence and noise*.
- Whisper's "Субтитры сделал …" lines are no longer typed.
- The model list shows the version and the model size (e.g. *v3.1 · Whisper Small*).

**Updating:** VoiceFlow AI shows an **Update** button in the sidebar, or run the installer — all your data is kept.

**macOS:** open the DMG and drag *VoiceFlow AI* into *Applications*. Before the first start, open **Terminal** and run once:

```bash
xattr -dr com.apple.quarantine "/Applications/VoiceFlow AI.app"
```

(the app is not signed with an Apple Developer ID, so without this macOS says it “cannot be opened”). macOS asks once for *Microphone*, *Accessibility* (to paste) and *Input Monitoring* (to notice the dictation key, Right Option ⌥). Speech engine: `brew install whisper-cpp`.

**Windows:** the installer is not code-signed — if SmartScreen warns, click *More info → Run anyway*.

## Что нового

**VoiceFlow AI 1.0.8** — таджикская модель лучше, и тишина с шумом больше не превращаются в выдуманный текст.

- **Новая таджикская модель v3.1** ([whisper-large-tajik](https://github.com/imomzoda-dev/whisper-large-tajik)): обучена примерно на 220 часах таджикской речи. Ошибок меньше — 14,4% слов на FLEURS (v2: 15,5%, первая модель: 22,3%), 36,7% на живой речи (v2: 38,6%) — и правильные заглавные буквы, запятые, точки и таджикские буквы (ғ ӣ қ ӯ ҳ ҷ). Если таджикская модель у вас уже стоит, она заменится сама через несколько секунд после обновления.
- **Следующие таджикские модели будут приходить сами**, в том числе переход на большую модель (Large v3 Turbo): каждый новый релиз проверяется (размер и SHA-256) и подключается между диктовками.
- **Тишина и шум не дают текста.** VoiceFlow AI теперь распознаёт только те места записи, где говорят (определение речи, VAD). Раньше пауза, вентилятор или шум улицы могли превратиться в целое выдуманное предложение. Заодно быстрее. *Настройки → Распознавание → Пропускать тишину и шум*.
- Строки Whisper вида «Субтитры сделал …» больше не печатаются.
- В списке моделей видны версия и размер модели (например, *v3.1 · Whisper Small*).

**Обновление:** кнопка **«Обновить»** в боковой панели или установщик — все данные сохраняются.

**macOS:** откройте DMG и перетащите *VoiceFlow AI* в *Программы*. Перед первым запуском откройте **Терминал** и один раз выполните:

```bash
xattr -dr com.apple.quarantine "/Applications/VoiceFlow AI.app"
```

(приложение не подписано Apple Developer ID, без этого macOS пишет «не удаётся открыть»). macOS один раз спросит доступ к *Микрофону*, *Универсальному доступу* (для вставки) и *Мониторингу ввода* (клавиша диктовки — правый Option ⌥). Движок речи: `brew install whisper-cpp`.

**Windows:** установщик не подписан — если SmartScreen предупредит, нажмите «Подробнее → Выполнить в любом случае».

- **Модели нави тоҷикӣ v3.1** ([whisper-large-tajik](https://github.com/imomzoda-dev/whisper-large-tajik)): дар тақрибан 220 соат нутқи тоҷикӣ омӯзонида шудааст.
